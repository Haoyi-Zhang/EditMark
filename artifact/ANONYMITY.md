# Anonymity and Release Boundary

This package is intended for double-anonymous review. It intentionally avoids author identity, institution identity, direct public archive links, private infrastructure details, credentials, and local machine paths.

The repository may still cite or link to third-party upstream software when that information is necessary to identify external baseline implementations. Such links are method provenance, not author identity.

After review, the authors can replace the anonymous artifact shell with a public archival record and non-anonymous citation metadata.
