# Method-integration scope

The archived matrix contains integrations for KGW, SWEET, STONE, and EWD. Their presence is a property of the included implementation, not a claim that they are the universally strongest or most representative watermark methods.

The paper distinguishes the original publications from local integration choices. In particular, EWD was introduced for text; using it in a code pipeline does not turn its original evaluation into a code-watermark result. Related methods are discussed without assigning them unobserved scores.
